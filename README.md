# SmartShelf

Simple inventory and credit (udhaar) tracker for small shops.

- Frontend: HTML, CSS, JavaScript (in `static/`)
- Backend: Python + Flask (`main.py`)
- Database: local SQLite file (`smartshelf.db`, created automatically)

## Run

    pip install -r requirements.txt
    python main.py

Then open http://127.0.0.1:5000
